Focus Cat Updates
# 🐱 집중 고양이 · Focus Cat

작업할 때 곁을 지켜주는 작은 도트 고양이입니다.

유튜브를 보고 있으면 집중하라고 알려주고, 쓰다듬으면 반응해요.
집중 타이머와 격언으로 할 일을 시작하는 데 도움을 줍니다.

Windows용 데스크톱 앱입니다.

## 📥 다운로드 및 설치

### 1. 설치 파일 다운로드

👉 [최신 버전 다운로드](https://github.com/thronpoly/focus-cat-updates/releases/latest)

릴리스 페이지 아래의 **Assets**에서
`focus-cat-v버전번호.zip` 파일을 다운로드해 주세요.

예: `focus-cat-v1.0.9.zip`

- `Source code (zip)`과 `Source code (tar.gz)`은 설치 파일이 아닙니다.
- `.sha256` 파일은 다운로드 파일의 무결성을 확인하는 용도입니다. 일반 설치에는 ZIP만 있으면 됩니다.

### 2. 압축 해제

ZIP을 원하는 폴더에 압축 해제해 주세요.

추천 설치 경로:

    C:\Users\사용자이름\Apps\FocusCat

다운로드 폴더나 임시 폴더보다는 계속 보관할 폴더를 권장합니다.

> 압축파일 안에서 바로 실행하지 말고, 먼저 압축을 모두 풀어 주세요.
> 폴더 안의 파일들은 함께 보관해 주세요.

### 3. 설치 및 실행

압축을 푼 폴더에서 **Install-FocusCat.exe**를 실행하세요.

설치가 완료되면 고양이가 나타나며,
다음 Windows 로그인부터 자동으로 실행됩니다.

설치 폴더를 옮겼다면 새 위치에서 `Install-FocusCat.exe`를 다시 실행해 주세요.

## ✨ 주요 기능

### 유튜브 감시

사용 중인 창 제목에 YouTube가 표시되면 고양이가 반응합니다.

- 얼굴에 빨간 표시가 나타납니다.
- 꼬리가 더 빠르게 움직입니다.
- 집중하라는 말풍선과 알림을 보여줍니다.

창 제목을 기준으로 감지하므로, 브라우저나 창 상태에 따라 감지되지 않을 수 있습니다.

### 쓰다듬기

고양이를 클릭하면 세 가지 대사 중 하나로 반응합니다.

“골골골… 쓰다듬어줘서 고마워!”라는 대사가 나오면
눈 모양이 바뀌고 고개를 살짝 끄덕입니다.

### 집중 한마디

고양이 우클릭 → **집중 한마디**

등록된 격언 중 하나를 무작위로 보여줍니다.

- 인물의 영어 이름과 연대를 함께 표시합니다.
- A.D.는 서기, B.C.는 기원전입니다.
- 격언을 말하는 동안 초록색 안경을 쓰고 눈 모양이 바뀝니다.
- 시작할 때 고개를 살짝 끄덕이며, 대사가 끝나면 원래 모습으로 돌아옵니다.
- 인터넷 연결 없이 사용할 수 있습니다.

일부 인물의 연대는 정확한 생몰연도 대신 추정 시대를 표시합니다.

### 집중·휴식 타이머

고양이 또는 시스템 트레이 아이콘을 우클릭해 사용하세요.

- **25분 집중 시작**
- **5분 휴식 시작**
- **타이머 중지**

남은 시간은 메뉴와 트레이 아이콘의 툴팁에서 확인할 수 있습니다.

시간이 끝나면 말풍선과 Windows 알림으로 알려줍니다.
휴식 중에는 유튜브 감시를 잠시 쉽니다.

### 위치 이동

고양이를 마우스로 드래그해 원하는 위치로 옮길 수 있습니다.

- 다른 모니터로도 이동할 수 있습니다.
- 작업표시줄을 제외한 화면 작업 영역 안에서 이동합니다.
- 마지막 위치를 기억합니다.
- 고양이는 일반 창 위에 표시됩니다.

### 숨기기·다시 보이기

고양이를 우클릭한 뒤 **숨기기**를 선택하세요.

다시 보고 싶다면 작업표시줄 오른쪽의 시스템 트레이에서
고양이 아이콘을 우클릭하고 **고양이 표시**를 선택하세요.

아이콘이 보이지 않으면 작업표시줄의 `∧` 버튼을 눌러 확인하세요.

### 감시 일시정지

고양이 또는 트레이 아이콘 우클릭 →
**유튜브 감시 일시정지**

다시 시작하려면 같은 메뉴에서 **유튜브 감시 다시 시작**을 선택하세요.

감시를 멈춰도 집중·휴식 타이머는 계속 작동합니다.

## 🔄 업데이트

실행할 때 GitHub에서 새 버전을 확인합니다.

업데이트가 있으면 고양이가 “업데이트 할래?”라고 묻고,
화면 오른쪽 아래에 확인창이 표시됩니다.

- **예:** 업데이트 파일을 다운로드하고 검증한 뒤 설치합니다.
- **아니오 / 창 닫기:** 고양이 앱을 완전히 종료하고 다시 실행할 때까지 다시 묻지 않습니다.

업데이트에 실패하면 자동으로 반복해서 묻지 않습니다.
시스템 트레이의 업데이트 메뉴에서 직접 재시도할 수 있습니다.

### 수동 업데이트

자동 업데이트가 어렵거나 구버전에서 알림이 반복된다면:

1. 시스템 트레이에서 고양이를 완전히 종료합니다.
2. 최신 릴리스의 배포 ZIP을 다운로드합니다.
3. 기존 설치 폴더에 압축을 해제하고 파일을 덮어씁니다.
4. `Install-FocusCat.exe`를 실행합니다.

## 🛠 자주 묻는 질문

### 고양이가 보이지 않아요

시스템 트레이의 고양이 아이콘을 우클릭한 뒤
**고양이 표시**를 선택해 주세요.

화면 밖으로 이동했다면 **고양이 위치 초기화**를 사용하세요.

### 처음 실행할 때 Windows 경고가 떠요

코드 서명이나 다운로드 평판이 충분히 쌓이지 않은 앱은
Windows에서 경고를 표시할 수 있습니다.

공식 저장소에서 받은 파일인지 확인하고,
파일의 출처가 의심되면 실행하지 마세요.

### 다른 컴퓨터에서도 사용할 수 있나요?

Windows PC에 배포 ZIP을 다운로드하고 압축을 푼 뒤
`Install-FocusCat.exe`를 실행하면 됩니다.

### 앱을 종료하려면 어떻게 하나요?

고양이 또는 시스템 트레이 아이콘을 우클릭하고
**종료**를 선택하세요.

숨기기는 종료가 아닙니다.

### 삭제하려면 어떻게 하나요?

설치 폴더의 **Uninstall-FocusCat.exe**를 실행해 주세요.
