
# 🐱 집중 고양이 · Focus Cat

작업할 때 곁을 지켜주는 작은 도트 고양이입니다.  
유튜브 감시, 집중 타이머, 격언으로 집중을 도와줍니다.

**Windows용 데스크톱 앱**

---

## 📥 설치하기

**[최신 버전 다운로드 →](https://github.com/thronpoly/focus-cat-updates/releases/latest)**

1. **Assets**에서 `focus-cat-v버전번호.zip`을 다운로드합니다.
2. 원하는 폴더에 **압축을 모두 해제**합니다.
3. **Install-FocusCat.exe**를 실행합니다.

설치 후 바로 실행되며, 다음 Windows 로그인부터 자동으로 켜집니다.

> **추천 경로:** `C:\Users\사용자이름\Apps\FocusCat`  
> `Source code`는 설치 파일이 아닙니다. `.sha256`은 검증용 파일입니다.  
> 설치 폴더의 파일들은 함께 보관해 주세요.

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 유튜브 감시 | YouTube 창을 감지하면 빨간 표정과 빠른 꼬리 움직임으로 집중을 알려줘요. |
| 쓰다듬기 | 클릭하면 세 가지 대사와 표정으로 반응해요. |
| 집중 한마디 | 등록된 격언을 무작위로 보여줘요. 초록 안경을 쓰고 고개도 끄덕여요. |
| 집중·휴식 타이머 | 25분 집중 / 5분 휴식 타이머를 사용할 수 있어요. |
| 위치 이동 | 드래그로 다른 모니터까지 이동하고, 마지막 위치를 기억해요. |
| 자동 업데이트 | 새 버전이 있으면 설치할지 물어봐요. |

## 🖱 사용 방법

- **클릭** → 쓰다듬기
- **드래그** → 위치 이동
- **고양이 우클릭** → 격언, 타이머, 감시 일시정지, 숨기기, 종료
- **트레이 아이콘 우클릭** → 고양이 다시 표시, 위치 초기화 등

고양이를 숨겼다면 작업표시줄 오른쪽 **`∧` → 고양이 아이콘 → 고양이 표시**를 선택하세요.

> 휴식 타이머 중에는 유튜브 감시를 잠시 쉽니다.  
> 유튜브는 창 제목으로 감지하므로 브라우저 상태에 따라 감지되지 않을 수 있습니다.

## 🔄 업데이트

새 버전이 있으면 고양이가 **“업데이트 할래?”**라고 물어봅니다.

- **예** → 다운로드·검증 후 설치
- **아니오 / 창 닫기** → 다음 앱 실행까지 다시 묻지 않음

자동 업데이트가 어렵다면 고양이를 **완전히 종료**하고, 최신 ZIP을 기존 설치 폴더에 덮어쓴 뒤 `Install-FocusCat.exe`를 실행하세요.

## 🛠 문제 해결

**고양이가 안 보여요**  
트레이 메뉴에서 **고양이 표시** 또는 **고양이 위치 초기화**를 선택하세요.

**Windows 실행 경고가 떠요**  
코드 서명이나 다운로드 평판이 부족하면 경고가 뜰 수 있습니다. 공식 저장소에서 받은 파일인지 확인하세요.

**삭제하고 싶어요**  
설치 폴더의 **Uninstall-FocusCat.exe**를 실행하세요.
